Information Before you install

Questions before you install

Does it change my document?

No. The extension applies reversible reading settings in your browser.

Why does it need site access?

It uses site access to apply the profile assigned to the current address.

What happens to sensitive fields?

Password and common payment fields keep their original styling and are not enlarged.

Is this a screen reader?

No. It changes visual presentation.
