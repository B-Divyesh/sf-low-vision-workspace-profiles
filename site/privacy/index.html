How your profile data is handled

Effective 28 August 2026

Workspace Profiles works without an account. The extension stores profiles and site assignments in Chromium extension storage.

Data the extension handles

  • Profile names and selected reading settings.
  • Site addresses you assign to a profile.
  • A JSON file when you choose to export a backup.

Data the extension sends

The extension sends no page text, form values, profile settings, or browsing history. It contains no analytics or advertising code.

Site access

Site access lets the extension apply the profile assigned to the current address. Password and common payment fields are excluded from its visual changes.

Demo data

The website demo uses a separate key whose name starts with demo:. Reset demo removes that sample key. The demo does not read extension data.

Delete your data

Delete profiles inside the extension or remove its browser data. Clear this website’s data to remove demo settings.
